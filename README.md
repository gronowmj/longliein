# The Long Lie-In

A private, original platform adventure for iPhone (landscape), in a classic 8-bit style.
Plain HTML/CSS/JS, no build step.

Run locally: `cd site && python3 -m http.server 8123`, then open http://localhost:8123/

Touch: hold the left/right arrows to walk, tap JUMP (hold a direction and tap JUMP for a running jump),
stand still for a moment at a door or ladder and tap JUMP to use it, tap a pocket to drop what's in it,
plus pause and mute. Progress saves automatically.
Keys: arrows or A/D to move, Space/Up/W to jump, P/Esc to pause, M to mute, 1/2 to drop.
